# KYXO

KYXO (KYELESS YIELD XFER OFFLINE) is a local-first, browser-based peer-to-peer file transfer application.

## Phase 1 status

This phase establishes the foundation:

- Vite + TypeScript project scaffold
- Responsive home screen
- Local-first UI messaging
- installable manifest shell

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
